# Security policy

## Safe defaults

- The audit uses the microCMS Content API and should receive a read-only API key.
- This project does not publish to microCMS automatically.
- Drafts and proposals are for human review; a person must approve factual, legal, financial, brand, and image changes.
- Never put API keys, GA4 exports, customer data, or production content in Git.

## Reporting a vulnerability

Please open a private security report through GitHub if the repository supports it. Do not include credentials or personal data in a public issue.
